# Initial solver results

The default command solves the two no-repost/no-history parameter pairs used
to represent the two pathway regimes. The recommendation kernel is random,
`epsilon=0.45`, `mean_degree=15`, and `recsys_count=10`.

## Main results

| case | alpha | q | D0 | path | Iw | first Ip >= 0.5 | first Ih >= 0.5 |
|---|---:|---:|---:|---|---:|---:|---:|
| PbS candidate | 0.05 | 0.025 | 0 | PbS | 0.392 | 65 | 130 |
| SbP candidate | 0.005 | 0.025 | 0 | SbP | 0.962 | 890 | 170 |
| PbS candidate | 0.05 | 0.025 | 1e-5 | PbS | 0.389 | 65 | 135 |
| SbP candidate | 0.005 | 0.025 | 1e-5 | SbP | 0.957 | 905 | 175 |

The small reflecting diffusion removes grid-locked delta peaks and the late
oscillation of the subjective index without changing the inferred pathway.
It is therefore preferable for numerical continuation, while the noiseless
run remains useful as the direct deterministic limit.

## Grid check with D0 = 1e-5

| grid | PbS Iw | PbS (tP, tH) | SbP Iw | SbP (tP, tH) |
|---:|---:|---:|---:|---:|
| 61 | 0.404 | (70, 130) | 0.958 | (930, 180) |
| 81 | 0.388 | (70, 140) | 0.957 | (910, 180) |
| 101 | 0.374 | (70, 140) | 0.957 | (900, 180) |
| 121 | 0.367 | (60, 140) | 0.956 | (870, 180) |

The pathway ordering and the separation in `Iw` are stable. The deterministic
late-time peak positions are grid-sensitive because the zero-diffusion
solution approaches singular opinion clusters; this is the main reason for
retaining the optional diffusion term.

## Complete 8-by-8 mesoscopic sweep

The full paper grid was solved for 4,000 steps using `p=0`, `k_h=0`, random
recommendation, and `D0=1e-5`. All 64 trajectories are generated by the
Python density solver; the Go microscopic simulator is not invoked.

- 56 cells crossed both `I_p=0.5` and `I_h=0.5` within the time horizon;
- 21 were PbS by first passage, 26 were SbP, and 9 reached the recorded
  thresholds simultaneously;
- 8 cells did not reach `I_p=0.5`; every cell reached `I_h=0.5`;
- `I_w` ranges from 0.257 to 0.999.

The central parameter region shows the expected transition with increasing
`q/alpha`. The `alpha=1` column is exceptional: rapid opinion motion itself
makes linked endpoints concordant, driving `I_h` toward one even when
rewiring is slow. This demonstrates that the present `I_h` is a joint
opinion--edge observable, not a topology-only segregation coordinate; high
`I_w` in this column should not be interpreted as unambiguous SbP.

The sweep command and outputs are:

```sh
python -m works.sweep_kinetic
```
